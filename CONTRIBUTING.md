# Contributing to NOVA Workspace

Thanks for considering a contribution!

## Ways to help

- Report reproducible bugs with browser, operating system and steps.
- Suggest focused improvements through GitHub Issues.
- Improve accessibility, performance, documentation or translations.
- Submit small, reviewable pull requests.

## Development

NOVA is currently a dependency-free HTML, CSS and JavaScript PWA. You can run it locally with a static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Pull request checklist

- Keep the app lightweight and usable on older computers and phones.
- Do not add tracking, ads, remote fonts or unnecessary dependencies.
- Never transmit or expose user notes, tasks or backups.
- Explain the problem and the change in your pull request.
- Test notes, tasks, projects, search, import/export and mobile layout when relevant.
- Update documentation when behaviour changes.

Please do not include passwords, API keys, private data or real personal information in issues, commits or test fixtures.
