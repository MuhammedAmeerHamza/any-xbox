# Compatibility reports

This folder is reserved for reproducible per-title test reports.

No commercial game is currently claimed to boot or run in this project. Do not add a title as compatible without a repeatable test, exact build identifier, target hardware, test environment, and logs.

Suggested report fields:

- Title and title/build identifier (avoid copyrighted assets)
- Console generation
- Test date and project commit
- Test hardware and operating system
- Test case and exact result
- Status: `not-tested`, `does-not-boot`, `boots`, `in-game`, or `playable`
- Known issues and evidence/log references

"Playable" requires sustained gameplay testing, not merely reaching a splash screen or menu.
